# Mohamed Emad

PhD student in control and haptics at King Fahd University of Petroleum and Minerals (KFUPM), Dhahran.

I work on teleoperation and haptics for surgical robots. My research is a tele-robotic stabilization system for beating-heart surgery, where one robot arm keeps the surgeon's view steady on the moving heart and a second arm carries the tool.

**Portfolio:** https://mohamed15elhgrse.github.io/

## Current work

- **Tele-robotic stabilization for beating-heart surgery.** PhD research with two Franka Research 3 arms and a Force Dimension Sigma.7 haptic device, built on ROS 2, Gazebo and Pinocchio.
- **Teleoperation in medical and surgical robotics: a systematic review.** 16,668 records from PubMed, Scopus and Google Scholar, reduced to 6,602 for screening.
- **Contact-minimal cooperative grasping of convex polyhedral objects with fully-actuated hexarotors.** Manuscript in preparation.
- **Object handover between two robot arms with haptic cues.** Course project with a user study comparing manual and assisted release.

## Completed projects

- **Fuzzy–ANFIS formation control for swarms of ground robots.** MATLAB, up to 40 followers with obstacle avoidance.
- **Energy-optimal tilt scheduling for a quad-tilt-wing UAV.** MATLAB, SDRE–LQR flight control.
- **Noise-resilient ARX model of a quadcopter in hover.** MATLAB, system identification tuned with a genetic algorithm.
- **H∞, PID and pole-placement control of a quadcopter.** MATLAB and Simulink.
- **Five-degree-of-freedom robot arm.** Graduation project in SolidWorks and MATLAB.

The code for these projects is in private repositories. I can share access on request.
